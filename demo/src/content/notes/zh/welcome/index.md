这个小站是 **astro-inkbrush 的可运行示范**——一个给 Astro 的极小
git-backed CMS。你看到的每一页都是 `src/content/notes/` 里的普通
Markdown 文件,由一个完全普通的 Astro 站点、一份完全普通的样式表渲染。
引擎只添了一件事:让这些文件可以**在页面上原地编辑**。

## 两种运行方式

阅读模式,就是你现在看到的:

```bash
cd demo && npm install
npm run build        # 或 npm run dev
```

编辑模式才是好戏:

```bash
npm run wiki         # WIKI=1 astro dev
```

打开站点,点右上角**登录**(示范站用本地快速登录——昵称加邮箱,无口令),
然后把鼠标悬到任意段落上。页边会浮出一个小手柄,带三个动作:

- ✎ —— 原地编辑这个块的 Markdown 源码
- ✦ —— 让 Claude 改写这个块
- ⟲ —— 这个块的修订历史,一键回滚

## 顺带一个方言演示

中文技术写作里,强调常常紧贴着标点。**报文。**同时,这一句里的加粗照常
生效——这正是引擎的 CJK 友好方言:按标准 CommonMark,紧邻中文标点的
`**` 会解析失败而把星号原样漏在页面上;这里的解析器把 CJK 标点当作
一等公民。单个 `~` 也不会被当成删除线,所以「约 ~2 分钟」这种写法是
安全的。
